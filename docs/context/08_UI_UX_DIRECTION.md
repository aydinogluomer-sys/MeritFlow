# UI/UX Direction

## Visual Direction

- Premium SaaS dashboard
- HR-tech / finance-grade güven hissi
- Temiz, sakin, profesyonel
- Aşırı oyunlaştırılmış çocukça tasarım yok
- Soft gamification
- Açıklanabilir veri görselleştirmesi
- Çalışanı baskılamayan leaderboard

## Employee UX

Çalışan şu soruların cevabını net görmeli:

- Bana hangi görevler atanmış?
- Hangi görevlerden puan aldım?
- Bu puanı neden aldım?
- Puanım pending mi approved mı?
- Tahmini primim ne?
- Prim nasıl hesaplandı?
- İtiraz edebilir miyim?
- Dönem ne zaman kapanıyor?

## Manager UX

Manager şu işleri hızlı yapabilmeli:

- Review queue görmek
- Görev approve/reject/revision yapmak
- Kalite puanı vermek
- Takım puanlarını görmek
- Anomaly/fairness uyarılarını görmek
- Puan override gerekiyorsa reason girmek

## HR UX

HR şu işleri yapabilmeli:

- Bonus dönemlerini yönetmek
- Bonus policy versiyonlarını görmek
- Dispute çözmek
- Fairness analytics görmek
- Dönem kapatmak
- Calculation snapshot approve etmek

## Finance UX

Finance şu işleri yapabilmeli:

- Bonus pool görmek
- Allocation snapshot görmek
- Payment export almak
- Paid olarak işaretlemek
- Clawback review görmek

## Leaderboard UX Rules

- Global public leaderboard default kapalı
- Employee kendi percentile’ını görür
- Yakın sıralama anonim gösterilebilir
- “En kötü çalışan” dili yasak
- Pozitif ve sakin dil kullan
