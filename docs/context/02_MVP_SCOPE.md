# MVP Scope

## MVP’de Olacaklar

- Auth
- Organization oluşturma
- Kullanıcı davet etme
- Roller: Owner, Admin, Manager, Employee, HR, Finance, Auditor
- Takım yönetimi
- Görev oluşturma
- Görev atama
- Görev teslim etme
- Manager review
- Görev onay/red/revizyon akışı
- Basit scoring policy
- Point ledger
- Monthly bonus period
- Bonus pool
- Pro-rata bonus calculation
- Bonus allocation snapshot
- Employee bonus breakdown
- Manager review queue
- HR bonus approval
- Finance payout export
- Basic dispute system
- Audit log
- Basic leaderboard
- Basic anti-gaming flags

## MVP’de Olmayacaklar

- Mikroservis
- RabbitMQ/Kafka
- Bordro entegrasyonu
- Otomatik vergi/SGK hesaplama
- AI ile otomatik performans puanı
- Kamera/mikrofon/ekran/mouse/konum takibi
- GNN tabanlı collusion detection
- Mobil uygulama
- Çok ülkeli payroll compliance
- Karmaşık OKR sistemi
- Full real-time multiplayer gamification
- Public global leaderboard
